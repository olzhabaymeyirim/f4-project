## Project Description
This is a group project for the Moon & Movies website. We created contact and registration forms with validation.

## Features
- Required fields
- Email validation
- Password confirmation
- Success and error messages
- Reset button
- Responsive design

## Technologies

- CSS
- JavaScript
- Bootstrap 5
